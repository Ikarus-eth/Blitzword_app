# Standalone continuous maps

The shareable Hidden Atlas uses the main game’s four continuous 4096×2731 scenes from Sleeping Waterwheel onward, with the same twelve whole-picture questions. Crystal Ferry retains its original image and three questions. No image generation was required.

All new reading text, choices and hints are available in English and German. German is a temporary standalone-only feature; no voice is included. Choices remain below the image. Wrong submitted answers cost one life. The independent save key and language preference are retained. Content revision migration preserves solved-question counts and lives while clearing obsolete pending selections.

Validation: 367 unit tests and 116 UI-flow groups pass. Twenty browser journeys cover all five maps in both languages at desktop and phone sizes, including image resolution, zoom, picture taps, all answers, life deductions, zero-life retry, reload, completion and isolated saves. German translation coverage includes every new clue, option and hint. Deployment verification pending.

# Closer choices, number duels, defeat and shields

September 23 gameplay batch, approved priorities 1–4 from the next-steps list.

## Reading choices

All 200 practice distractor sets were individually reviewed. Sets use close real words and plausible misspellings, including vowel changes and transpositions. Every multi-letter target has at least two same-initial alternatives and every target has a same-length alternative. The single-letter targets use letter alternatives. Treasure now uses traesure, trasure and treason. Assessment pools and existing saved question choices remain unchanged; curriculum targets, sentences and order are unchanged. This is an editorial review, not a validated measurement of child reading difficulty.

## Number duels

Four large buttons replace the keypad and typed-answer keyboard handler. Choices contain exactly one answer and three distinct plausible alternatives based on nearby multiplication facts or small numeric errors, all 1–100. Choice order is shuffled once, saved and restored. Only an offered answer can score; repeated or queued taps from a prior question cannot answer a later one. Feedback locks the buttons before the next question.

The duration remains 60 active foreground seconds, with factors 1–10, net +1/−1 scoring, permanent XP for correct responses and the existing PR-minus-two target (minimum one). Existing records and PR are preserved; new answers identify their input mode as choice. Pending legacy rounds keep their factor pair, elapsed time, score, target and accepted answers. Unsubmitted typed digits are archived on the question and no longer displayed as input. There is no selectable typed-answer mode.

## Defeat

A lost reading battle or number duel briefly shows the actual enemy chuckling and running away over the result screen, with a short synthesized chuckle cue. This happens only after combat/duel resolution; never during fixation, exposure, choices or teaching. It does not take XP or cleared places away. It is persisted as shown before playback and cancels on Pause/Home. Reduced-motion users see a static escaped state instead of bouncing/travelling motion. A held isolated review fixture supports checking the pose without touching learner storage.

## Shield

Three campaign reading victories followed by a won number duel earn one shield. Reading losses, failed duels and skipped duels reset reward progress. Demo battles do not count. Old saves start with no retroactive reward. A held shield survives reloads and cannot stack or accumulate spare charges.

The shield absorbs the next independent campaign-reading mistake that would otherwise remove a heart. The mistake is still recorded and receives normal correction/teaching. Help, correct answers, free demo mistakes, teaching and number-duel mistakes do not consume it. The blocked attack follows narration, preserves all three hearts and displays the shield reaction. The next damaging mistake removes a heart normally. A later won cycle can earn a replacement.

Shield icons appear in the battle HUD, map, reading result and earned-duel reward. Existing character art, growth/paid-access gates, chapter checkpoints, 165 recordings and deferred narration scope remain intact. Background soundscape redesign is not included.

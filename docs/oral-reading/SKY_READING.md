Implemented: one original passage of about 55–65 words for each of the eight Sky Stars missions. A map entry selects the current/next mission; each mission introduction offers its own message. The screen preserves the saved game and returns through the normal game entry. The existing nine tasks remain unchanged; this is optional connected reading, not a replacement fight or completion requirement.

Target one sample daily, around 60–90 seconds. Finishing sooner is fine. Microphone capture stops at two minutes; backgrounding stops it too. Read the full short passage without a speed target. If stopped early, a parent should trim the reference to the attempted excerpt before submitting, otherwise the unread ending is counted as omissions. Eight passages are a starting set, not an unlimited supply of unseen daily assessments. Reused passages are marked as rereads; fresh comparable passages can still be uploaded from Parents.

The same browser recording screen supports Record, Stop, playback, audio download, and explicit Send. Microphone access requires permission; unsupported or denied microphones retain file upload. Capture can work without pairing, but Azure assessment and report sync require the existing paired browser and connection. Audio is held in memory only; keep the downloadable recording before leaving if needed. Reports use the existing durable retry queue; no new backend or credentials.

Each passage has a single comprehension question. Its first selection is recorded in report notes, separately from automated speech scores. Help/reread flags remain editable. Starting a recording marks that passage as seen on this device for the next attempt, including recordings not submitted; this marker is not cross-device evidence. Passage ID/version, full text and selected meaning answer accompany reports. Child mode hides numeric assessment results. No scores gate progress and no extra XP is awarded.

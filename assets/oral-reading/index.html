    Azure setup and cost
    1. In the Azure portal, create a Speech resource. Choose Free F0 if available, and note its region.
    2. Open the resource’s Keys and Endpoint. Keep the key private; do not paste it into the game or GitHub.
    3. Configure the progress service’s server secrets as AZURE_SPEECH_KEY and AZURE_SPEECH_REGION, then redeploy that service. The region is a code such as southeastasia.
    4. Return here and reload. Test one recording and check its flagged words by listening before relying on trends.

    Free F0 includes 5 audio hours/month. At the Singapore standard rate checked on 11 October 2026, $1/hour is about 3.3 US cents per 2-minute recording, or $1 for 30 daily recordings. Taxes, retries and other Azure usage are extra. No paid prosody add-on is enabled. Check current Azure pricing.

    The app allows ten starts per paired device per UTC day. This is not a hard Azure spending cap; use a dedicated Speech resource and Azure billing alerts for paid accounts.

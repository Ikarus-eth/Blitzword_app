# Ten complementary creature families

30 standalone concept pictures for selection. Created 20 November 2026 with built-in ImageGen. Proposed art only: no creature has been added to gameplay, and this branch is not deployed.

Each row compares **A Storybook**, **B Elemental**, and **C Champion**. Open an image for its original PNG.

These species were checked against the 65 active creature families in `content.js` / approved selections, the 35-species November review catalog, and this chat's tiger, phoenix and octopus. None repeats a listed species. The new set extends desert, grassland, coastal, pelagic, forest-floor, canopy and prehistoric silhouettes while retaining the warm painted fantasy style. Bison is deliberately shoulder-heavy rather than the existing yak's long all-over coat; nautilus has an external shell and fine tentacles rather than an octopus body.

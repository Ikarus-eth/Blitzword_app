# Next ten creature families

Thirty standalone selection concepts, created 20 November 2026 with built-in ImageGen. Proposed artwork only; not implemented or deployed. Each species has A Storybook, B Elemental and C Champion.

Species checked against the 65 game families, the earlier 35-concept catalog, the tiger/phoenix/octopus set and the preceding ten-species batch. This set adds ocean swimmers, reef invertebrates, coastal and canopy birds, desert rodents, woodland and savanna mammals, and a plate-backed dinosaur. The dolphin, puffin, jerboa and stegosaurus deliberately retain silhouettes distinct from the prior whale, penguin, kangaroo and triceratops.
